# Данные

Сами фото и разметка в git не хранятся (слишком большие), здесь только
описание структуры. Положите данные так:

```
data/
├── train/
│   ├── images/      # фото для обучения (*.png, *.jpg)
│   └── labels/      # разметка YOLO: по файлу *.txt на каждое фото
├── arvalis_3/       # фото для predict/compare с флагом --random
└── splits/          # создаётся командой split-data, вручную не трогать
```

Формат строки в файле разметки: `класс x_центра y_центра ширина высота`,
координаты от 0 до 1 относительно размеров фото. Класс один: `0` (колос).

Пути можно поменять в `configs/config.yaml` (раздел `paths`).
