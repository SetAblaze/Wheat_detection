# Изменения

## 1.0.0 (2026-10-23)

Рефакторинг под production-стандарты, Poetry, линтеры, pre-commit, CI.

### Структура кода

- Четыре скрипта из `scripts/` заменены пакетом `src/wheat_detection`
  с командой `wheat-detection` и подкомандами `predict`, `compare`,
  `split-data`, `train`.
- Общий код (загрузка модели, выбор случайного фото, подсчёт колосьев)
  больше не повторяется в трёх файлах.
- При импорте модулей ничего не запускается: вся работа в функциях,
  модель грузится только когда нужна.
- Настройки вынесены в `configs/config.yaml`, их можно менять
  переменными окружения и флагами без правки кода.
- Вместо `print` модуль `logging`, вместо молчаливых сбоев понятные
  сообщения и коды завершения (0 успех, 1 ошибка, 130 Ctrl+C).
- Аннотации типов и docstring у всех функций, mypy в строгом режиме.
- Тесты pytest, покрытие кода 96%.

### Исправленные ошибки

- В `config/dataset.yaml` был абсолютный путь
  `C:/Users/User/Desktop/wheat_detection/data`: проект запускался
  только на одном компьютере. Теперь пути относительные.
- Проверочная выборка совпадала с обучающей (`val: train/images`),
  поэтому метрики завышены. Команда `split-data` делит фото на
  непересекающиеся train и val с фиксированным seed.
- В `train.py` было жёстко `device=0`: без видеокарты обучение падало.
  Теперь `device: auto` (видеокарта, если есть, иначе процессор).
- В `befor_after_random.py` картинку из `results[0].plot()` (порядок
  каналов BGR) показывали как RGB: синий и красный менялись местами,
  на демо-видео рамки красные, а растения синеватые. Исправлено.
- Искались только `*.png`, теперь также jpg, jpeg, bmp, tif, webp.
- Результат каждый раз перезаписывал один и тот же файл, теперь имя
  берётся от исходного фото.
- `plt.show()` и `results[0].show()` останавливали скрипт и требовали
  графическое окно. Теперь результат сохраняется в файл, а показывается
  только с флагом `--show`.
- Путь к фото можно было только ввести вручную. Теперь его можно
  передать аргументом, взять случайно (`--random`) или ввести как раньше.
- `Image.open` без закрытия файла; опечатка в имени
  `befor_after_random.py`.

### Окружение и инструменты

- Poetry: `pyproject.toml`, `poetry.lock`, окружение в `.venv` внутри
  проекта (`poetry.toml`).
- pre-commit: black, isort, flake8 с bugbear, mypy, базовые проверки
  файлов, `poetry check --lock`.
- `.gitignore`, `.gitattributes` (переводы строк LF, веса через Git LFS),
  `.editorconfig`, `.env.example`.
- CI для GitLab и GitHub: проверки pre-commit и тесты.

### Что не вошло в репозиторий

- `yolov8n.pt`: ultralytics скачивает его сам при обучении.
- `models/last.pt`: промежуточная точка обучения, для работы не нужна.
- Демо-видео (40 МБ): большим файлам не место в git.
- Папка `results/` перенесена в `reports/baseline/`.
