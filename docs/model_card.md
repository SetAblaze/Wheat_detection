# Model Card: Детектор колосьев пшеницы (Wheat Detection)

## 1. Model Details (Детали модели)
*   **Разработчик:** В рамках проекта Wheat_detection.
*   **Тип модели:** Сверточная нейронная сеть для детекции объектов (Object Detection).
*   **Архитектура:** YOLOv8n (You Only Look Once, версия 8, нано-вариант). Легковесная модель, оптимизированная для быстрого инференса.
*   **Версия:** 1.0.0 (исходные веса `models/best.pt`).

## 2. Intended Use (Предполагаемое использование)
*   **Основное использование:** Автоматическое обнаружение и подсчет колосьев пшеницы на фотографиях поля для оценки урожайности и анализа состояния посевов.
*   **Нецелевое использование:** Модель не предназначена для определения болезней растений, классификации сортов пшеницы или для работы с изображениями, где колосья не являются доминирующим объектом (например, городские пейзажи).

## 3. Factors (Факторы)
На качество предсказания модели могут влиять следующие факторы:
*   **Освещение:** Сильные тени или пасмурная погода могут снизить точность.
*   **Ракурс и высота съемки:** Модель может быть чувствительна к углу обзора дрона.
*   **Зашумленность:** Наличие плотного сорняка или других культур может привести к ложным срабатываниям.
*   **Разрешение:** Из-за масштабирования до 640x640 очень мелкие колосья на исходных фотографиях высокого разрешения могут быть не обнаружены.

## 4. Metrics (Метрики)
Для оценки качества модели используются стандартные метрики детекции объектов:
*   **Precision (Точность):** Доля верных срабатываний (сколько из найденных объектов действительно являются колосьями).
*   **Recall (Полнота):** Доля найденных объектов (сколько реальных колосьев модель смогла найти).
*   **mAP (Mean Average Precision):** Основная метрика, учитывающая точность определения координат (bounding box) и уверенность.

## 5. Evaluation Data (Данные для оценки)
*   **Датасет:** Исходный набор данных, на котором проводилась валидация (см. `reports/baseline/`).
*   **Примечание:** В исходной версии проекта валидация проводилась на тех же изображениях, что и обучение. Это может приводить к завышенным метрикам. Для получения честных результатов необходимо переобучение после команды `split-data`.

## 6. Training Data (Данные для обучения)
*   **Источник:** Собственный набор данных (см. `data/README.md`).
*   **Параметры обучения:** 50 эпох, размер батча (batch) 16, разрешение изображений 640x640.

## 7. Quantitative Analyses (Количественный анализ)
Согласно данным из `reports/baseline/`, исходная модель YOLOv8n показала следующие результаты:

| Метрика | Значение | Описание |
| :--- | :--- | :--- |
| **Precision** | 0.930 | Точность (доля верных срабатываний) |
| **Recall** | 0.907 | Полнота (доля найденных объектов) |
| **mAP50** | 0.964 | Средняя точность при IoU=0.5 |
| **mAP50-95** | 0.607 | Средняя точность при IoU от 0.5 до 0.95 |

## 8. Ethical Considerations (Этические соображения)
*   **Предвзятость:** Модель может быть предвзята к определенным регионам, если обучалась на данных только из одного места. Рекомендуется валидация на данных из целевого региона.
*   **Ограничение по сортам:** Модель не различает сорта пшеницы, поэтому ее использование для точной оценки урожайности конкретного сорта может быть ограничено.
*   **Влияние на труд:** Модель автоматизирует рутинный процесс подсчета, что может изменить обязанности агронома (смещение фокуса с ручного труда на анализ данных).

## 9. Caveats and Recommendations (Ограничения и рекомендации)
*   **Одиночный класс:** Модель детектирует только колосья пшеницы. Она не различает стадии зрелости или болезни растений.
*   **Производительность:** Благодаря архитектуре YOLOv8n, модель обеспечивает высокую скорость работы, в том числе на CPU.
*   **Порядок использования:** Для запуска инференса используется команда `poetry run wheat-detection predict путь/к/фото.png`.
